# Logos des technologies

Les SVG existants ont été conservés et vérifiés. Les ajouts sont servis localement, sans CDN au chargement du portfolio.

- [Devicon](https://github.com/devicons/devicon) : Swagger, Postman, CentOS, Nginx, MySQL, MongoDB, Jira, Kubernetes.
- [Simple Icons](https://github.com/simple-icons/simple-icons) : Spring Boot, LangGraph, Model Context Protocol ; Power BI issu de la version 11.15.0.
- [Hugging Face](https://huggingface.co/front/assets/huggingface_logo-noborder.svg) : logo multicolore utilisé pour la technologie et la certification.
- [Groq](https://groq.com/favicon.svg) et [Wazuh](https://wazuh.com/wp-content/themes/wazuh-v3/assets/images/favicon.ico) : icônes publiées par les sites des marques.

Les concepts RAG, CI/CD, SQL, SQL / NoSQL et DAX restent des libellés. LangSmith reste écrit en toutes lettres en l’absence d’un logo produit vérifié ; aucun logo de substitution n’est inventé. Les marques restent accompagnées de leur nom ; leurs images sont décoratives dans les listes de technologies.
