- [ReSlot AI](https://github.com/Ihssan-Salma/reslot-ai): the current raw README was read directly, rather than relying on an older web-search cache. Its **Current implementation** paragraph documents a durable four-agent workflow, controlled Gmail offers and secure Accept/Decline pages. A manager supplies verified cancellation evidence; automatic detection is not implemented. Acceptance stops at `READY_TO_CONFIRM`, without final Calendar / Sheets booking writes. Broader roadmap prose is not treated as shipped functionality.
- [Facial Emotion Recognition](https://github.com/Ihssan-Salma/DL_facial_emotion_recognition_project): seven FER2013 categories, CNN preprocessing/training, F1/confusion-matrix tooling, OpenCV tracking and prediction smoothing. No numerical evaluation artifact has been validated for this portfolio, so it shows a pipeline, not fabricated statistical charts. The repository's `video_demo.mp4` is **input footage**, not an annotated inference recording.
- [eGrading](https://github.com/eayzaid/eGrading): role-specific portals, React/TypeScript, Spring Boot, MySQL and MongoDB. Presented as a team project, with no unsupported individual ownership claim. Containerized deployment is described as in progress by the README.
- [Agile Tracker](https://github.com/Ihssan-Salma/agile-tracker): `ms-user-access`, `ms-scrum-core`, and `ms-time-and-reporting`, each with a PostgreSQL database separated by context. Discovery and gateway are foundations, not asserted production deployments.

The banking sequence is an **illustrative simplification** of the CV. Llama 3 / LangGraph / RAG / MCP are documented there. Python appears in the user's requested scene and skills. FastAPI is shown with ReSlot, not attributed to the banking internship without evidence. Plain text names are used where no verified local logo is available; no invented brand mark is substituted.
